Cloud Foundry Community APT repository - staging

When you find yourself on an Ubuntu/Debian machine and you just need your favourite CLIs.

wget -q -O - https://raw.githubusercontent.com/cloudfoundry-community/homebrew-cf/master/public.key | apt-key add -
echo "deb http://apt.community.cloudfoundry.org/staging stable main" | tee /etc/apt/sources.list.d/cloudfoundry-community.list
apt-get update

apt install safe
